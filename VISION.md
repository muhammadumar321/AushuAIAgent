# Aushu Vision

**Aushu** is on a mission to become the definitive open-source developer AI platform — a local-first, community-driven alternative to proprietary tools like Cursor, Copilot, and Codex.

## Mission

Empower every developer with AI workflows that are fast, private, and fully under their control. No cloud lock-in. No hidden telemetry. No per-seat pricing.

## Why this matters

The current generation of AI coding tools is dominated by closed-source platforms that:

- Send your code to third-party servers
- Lock you into specific models and pricing tiers
- Offer limited extensibility
- Operate as black boxes

Aushu exists to change that. We believe the best developer tools are open, transparent, and run where you want them to run.

## Principles

| Principle | Description |
|-----------|-------------|
| **Local-first** | Prefer self-hosted models (Ollama, vLLM, llama.cpp). Your code never needs to leave your machine. |
| **Developer-first UX** | Fast CLI for power users, beautiful browser UI for chat workflows. Both are first-class citizens. |
| **Extensible by design** | Pluggable provider adapters, tool system, and plugin architecture. Add what you need, nothing more. |
| **Privacy by default** | No telemetry, no data collection, no accounts required. What you run stays yours. |
| **Community-governed** | Roadmap, priorities, and design decisions are shaped by the community, not a single vendor. |

## Target audience

- **Solo developers** who want AI assistance without sending code to the cloud
- **Teams** that need self-hosted AI tooling for compliance or security
- **open-source enthusiasts** who want to build and customize their own AI agent
- **Researchers** experimenting with local LLMs and need a flexible evaluation platform
