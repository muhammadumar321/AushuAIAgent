# Aushu Vision

Aushu is an open-source, local-first developer AI agent built to compete with OpenCode, Cursor, and Codex.

## Mission

Enable developers to use powerful AI workflows while keeping code, prompts, and model execution under their control.

## Principles

- Local-first model support: prefer self-hosted models such as Ollama and other on-prem providers.
- Developer-first UX: fast CLI and chat-style browser workflows that match modern developer expectations.
- Extensible integrations: pluggable provider adapters for OpenAI, Ollama, and future self-hosted systems.
- Clear control: explicit provider selection, model discovery, and health/status feedback.
- Open architecture: avoid cloud-only lock-in and make the platform easy to extend.

## Differentiation

Aushu competes by focusing on:

- local and self-hosted LLM workflows,
- a polished chat UI and prompt-driven developer experience,
- provider transparency and model discovery,
- a small, easy-to-run Python monorepo rather than a closed SaaS product.

## Goals

- Make the web UI feel like a responsive, WhatsApp-style developer chat.
- Keep setup and onboarding friction low across Linux, macOS, and Windows.
- Make it easy to add new providers and tests without changing the core architecture.
- Build a trustworthy, privacy-aware alternative to closed-source development AI tools.
