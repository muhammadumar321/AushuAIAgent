# Aushu TUI

This package contains the terminal user interface scaffold for the Aushu agent monorepo.

## Purpose

The TUI package is intended to provide a console-first interface for developers who prefer terminal workflows. It is currently an initial scaffold package.

## Notes

- Build with `npm run build` from `packages/tui`.
- This package can be expanded with a terminal chat experience or developer dashboard in the future.

## Future work

- Add terminal chat-style interaction.
- Integrate with the core agent runtime for local prompt execution.
- Provide a complementary experience to the web UI and CLI.
