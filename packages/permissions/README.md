# packages/permissions

Aushu permission engine scaffold with three-tier configuration and rule evaluation.

## Purpose

This package provides permission configuration, policy evaluation, and safety checks for the Aushu agent runtime.

## Contents

- `aushu_permissions/checker.py` — permission evaluation logic.
- `aushu_permissions/config.py` — permission config loading and defaults.

## Usage

Install in editable mode and use permission checks as part of agent workflows to enforce rules before executing actions.
